I want to design a luxurious, minimalistic and modern web app for selling and showcasing high-end, luxurious real-estate. I want to base the colors on this pallete: #06362D, #9A7B36, #F9F6F0, #EADCC9, where I would use the green as primary color, the gold as secondary, and the white and beige colors for backgrounds and stuff. Now I will describe the pages and the sections I want you to design them as per the requirements:

# Homepage
## Header navbar
The navbar is located on top of the screen. It contains a hamburger icon on the left side which opens up a navigation menu on the left side when the hamburger icon is clicked. Next to the icon is the logo. On the right side of the navbar there is a call to action pill. When the page is at the top (Hero section) the navbar is transparent. Then when the user scrolls down, the navbar becomes dark green.
## Hero section
Contains an image which covers the whole screen with a dark overlay. There is a title and description text on the bottom left side of the image
## Call to action section
Contains 4 square box elements in a row. Each box is an image with a dark overlay and it contains a text in the bottom left side.
## Property showcase section
Contains 3 card elements in a row. There are arrows on the right and left sides of the row so that users can "scroll" through the items. Each card contains an image and some basic real-estate info below it. 
## Blogs showcase section
Contains a bento grid with 2 columns. The left column is an image with dark overlay and it contains a text in the bottom left side.
The right column contains 3 items in a vertical list. 
## Testimonials section
Contains a centered text element with arrows on the left/right sides which enable "scrolling" through the items, beige background.
## Subscribe to newsletter CTA section
Contains 2 columns, the left column contains a title and some text, the right column contains an email input field and a submit button.
## Footer
Contains the logo and copyright info on the left side, and social media icons on the right side
